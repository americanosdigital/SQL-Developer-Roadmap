## Module 01 — SQL Server Fundamentals

The first module contains 12 lessons:

1. Database creation
2. Tables and data types
3. INSERT INTO and SELECT
4. UPDATE, DELETE, and transactions
5. SQL operators and filtering
6. Aggregate functions, GROUP BY, and HAVING
7. Relationships and JOINs
8. Subqueries and EXISTS
9. Views
10. Indexes and execution plans
11. Transactions and error handling
12. Stored Procedures

## How to run

1. Install SQL Server and SQL Server Management Studio.
2. Open the `.sql` file in the `EN` folder using SSMS.
3. Run one lesson at a time and review the results.
4. Use the equivalent file in `PT-BR` to study in Portuguese.

**Important:** UPDATE, DELETE, COMMIT, and Stored Procedure examples may modify data. Run them only in a training database and read the comments before execution.
