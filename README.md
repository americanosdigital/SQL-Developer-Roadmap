# SQL Developer Roadmap

Repositório de estudos práticos para desenvolver conhecimentos em **SQL Server e T-SQL**, dos fundamentos a conceitos intermediários de desenvolvimento, otimização e integração de bancos de dados.

## Objetivo

Construir uma base sólida e demonstrável em SQL Server, desenvolvendo habilidades relevantes para atuar como **SQL Developer**, com foco em consultas, programação T-SQL, modelagem, performance, segurança e integração com aplicações.

## Tecnologias e ferramentas
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- Git e GitHub

## Roadmap de aprendizado

O roadmap está planejado em **6 módulos**, desenvolvidos e validados progressivamente.

| Status | Módulo | Conteúdo |
|---|---|---|
| Concluído | **Módulo 01 – Fundamentos de SQL** | Databases, tabelas, tipos de dados, CRUD, filtros, agregações, relacionamentos, JOINs, subqueries, views, índices, transações e stored procedures |
| Concluído | **Módulo 02 – Consultas SQL Intermediárias** | CASE, CTEs, UNION, window functions, ranking, PARTITION BY, APPLY e paginação |
| Em desenvolvimento | **Módulo 03 – Programação SQL e Objetos do Banco** | Variáveis, controle de fluxo, stored procedures, funções, triggers, tabelas temporárias, tratamento de erros e Dynamic SQL |
| Planejado | **Módulo 04 – Performance e Otimização** | Execution plans, índices, estatísticas, análise e otimização de consultas |
| Planejado | **Módulo 05 – Modelagem, Transações e Segurança** | Normalização, integridade referencial, ACID, isolamento, locks, deadlocks, permissões, backup e restore |
| Planejado | **Módulo 06 – Integração, ETL e Projetos Práticos** | Importação e exportação, conceitos de ETL, integração com .NET, relatórios e projeto prático |

> Os status refletem o andamento dos estudos e exercícios. Um módulo só será considerado concluído depois que seus exemplos forem executados e revisados.

## Banco de dados utilizado

Os exercícios utilizam o banco `SQLRoadmapTrainingDB`, criado no Módulo 01. Os módulos seguintes reutilizam as tabelas e os dados de treinamento desse banco.

Antes de executar um módulo, leia as instruções iniciais do respectivo arquivo `.sql` e confirme que os módulos anteriores necessários já foram executados.

## Como utilizar
1. Instale o Microsoft SQL Server e o SSMS.
2. Abra o arquivo `.sql` correspondente ao módulo.
3. Leia os comentários e execute uma aula por vez.
4. Confira os resultados e mensagens do SSMS.
5. Resolva os desafios propostos nos comentários.
6. Registre sua evolução e mantenha os scripts atualizados no GitHub.

# SQL Developer Roadmap

A hands-on learning repository focused on developing **SQL Server and T-SQL** skills, from the fundamentals to intermediate concepts used in database development, optimization, and integration.

## Objective

Build a solid, demonstrable SQL Server foundation and develop skills relevant to working as a **SQL Developer**, with a focus on queries, T-SQL programming, database design, performance, security, and application integration.

## Technologies and tools
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- Git and GitHub

## Learning roadmap

The roadmap is planned as **6 modules**, developed and validated progressively.

| Status | Module | Topics |
|---|---|---|
| Completed | **Module 01 – SQL Fundamentals** | Databases, tables, data types, CRUD, filtering, aggregates, relationships, JOINs, subqueries, views, indexes, transactions, and stored procedures |
| Completed | **Module 02 – Intermediate SQL Queries** | CASE, CTEs, UNION, window functions, ranking, PARTITION BY, APPLY, and pagination |
| In progress | **Module 03 – SQL Programming and Database Objects** | Variables, control flow, stored procedures, functions, triggers, temporary tables, error handling, and Dynamic SQL |
| Planned | **Module 04 – SQL Performance and Optimization** | Execution plans, indexes, statistics, query analysis, and optimization |
| Planned | **Module 05 – Database Design, Transactions, and Security** | Normalization, referential integrity, ACID, isolation levels, locks, deadlocks, permissions, backup, and restore |
| Planned | **Module 06 – Integration, ETL, and Practical Projects** | Data import and export, ETL concepts, .NET integration, reporting, and a practical project |

> Status reflects learning and exercise progress. A module is considered completed only after its examples have been executed and reviewed.

## Database

The exercises use the `SQLRoadmapTrainingDB` database created in Module 01. Later modules reuse the training tables and data from that database.

Before running a module, read the instructions at the beginning of its `.sql` file and make sure any required previous modules have already been executed.

## How to use this repository
1. Install Microsoft SQL Server and SSMS.
2. Open the `.sql` file for the module you want to study.
3. Read the comments and execute one lesson at a time.
4. Review the query results and SSMS messages.
5. Complete the exercises described in the comments.
6. Track your progress and keep the scripts updated on GitHub.
